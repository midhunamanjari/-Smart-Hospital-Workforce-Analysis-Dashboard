Smart Hospital Workforce Monitoring

An IoT-based analytics prototype: connected devices stream staff activity, and a dashboard turns it into workload and attrition insight.

System architecture

1. Sensing devicesRFID badge readers, wearable fatigue and heart-rate bands, smart door sensors in each department.
2. GatewayLocal hub per ward collects readings over MQTT or BLE and filters noise before sending.
3. Cloud storageTime-stamped events stored per employee: shift, overtime hours, leave, role.
4. Analytics dashboardThis web page: live alerts, KPIs and attrition insight for hospital managers.

Live device feed

Simulated stream: events are generated at random from the 5,000 employee records in the dataset, to demonstrate how real device data would appear.

Analytics layer

Data: Healthcare_Workforce_Operations_Dataset.csv (5,000 records). The device feed is simulated; filters apply to the feed and every chart.
